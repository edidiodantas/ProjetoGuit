FURYU2 — LEIA-ME DO PENDRIVE (português do Brasil)
==================================================

Esta pasta é o Furyu (pesquisa e leitura de artigos no PC, com IA local).
O nome Furyu2 evita conflito com outras pastas Furyu.

IMPORTANTE
----------
1. NÃO rode o programa de dentro do pendrive (exFAT quebra o .venv).
2. Copie a pasta Furyu2 INTEIRA para o disco do PC:
     Ubuntu:  ~/Furyu2
   Ou, se trouxe o .tar.gz:
     tar -xzf Furyu2-ubuntu-pendrive.tar.gz -C ~
3. Siga o guia IMPRESSO / TXT:
     INSTALAR-UBUNTU-LTS.txt   ← use este para acompanhar a instalação
   Ou o Markdown:
     INSTALAR-UBUNTU.md
4. Instalador automático:
     bash install-ubuntu.sh
5. Ollama + modelo:
     ollama pull qwen3.5:4b
     (PC fraco: qwen3.5:2b)
6. Abrir a interface:
     bash rodar-ubuntu.sh
7. Navegador: http://localhost:8501
   Título: Furyu · ícone de livro aberto simples

FLUXO DE ARTIGOS
----------------
1. Localizar (Buscar)
2. Baixar e indexar  OU  Abrir / Guardar link (para baixar depois)
   Links guardados: documentos/links_salvos.json

--------------------

    python testes/run_avaliacao.py
